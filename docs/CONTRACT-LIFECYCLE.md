## 1. TỔNG QUAN VÒNG ĐỜI HỢP ĐỒNG

### Sơ Đồ Trạng Thái

```
PROSPECT (Khách tiềm năng)
    │
    ↓ (Đặt cọc)
DEPOSITED (Đã đặt cọc)
    │
    ↓ (Ký hợp đồng)
DRAFT (Nháp)
    │
    ↓ (Kích hoạt)
ACTIVE (Đang hoạt động) ←──────────────┐
    │                                  │
    ├─→ EXTENDED (Đã gia hạn) ─────────┤
    ├─→ TRANSFERRED (Đã nhượng/chuyển) │
    ├─→ TERMINATED (Đã thanh lý)       │
    └─→ EXPIRED (Hết hạn)              │
```

### Database Tables Liên Quan

- **tenants** - Thông tin khách thuê
- **deposits** - Tiền cọc giữ chỗ
- **contracts** - Hợp đồng thuê
- **contract_services** - Dịch vụ trong hợp đồng
- **contract_extensions** - Lịch sử gia hạn
- **contract_transfers** - Lịch sử chuyển phòng/nhượng HĐ
- **contract_terminations** - Thanh lý hợp đồng
- **invoices** - Hóa đơn hàng tháng
- **payments** - Thanh toán

## 2. TẠO MỚI HỢP ĐỒNG (CHECK-IN)

### Quy Trình Tạo Hợp Đồng

#### Bước 1: Tạo/Chọn Khách Thuê

**Tạo mới khách thuê:**
```sql
INSERT INTO tenants (
  user_id, full_name, phone, email, id_number, id_type,
  date_of_birth, permanent_address, status
) VALUES (
  auth.uid(),
  'Nguyễn Văn A',
  '0901234567',
  'nguyenvana@example.com',
  '001234567890',
  'CCCD',
  '1990-01-01',
  '123 Đường ABC, Quận 1, TP.HCM',
  'PROSPECT'
);
```

**Hoặc chọn từ danh sách có sẵn:**
```sql
SELECT * FROM tenants
WHERE user_id = auth.uid()
  AND deleted_at IS NULL
ORDER BY created_at DESC;
```

#### Bước 2: Chọn Phòng/Giường

**Danh sách phòng trống:**
```sql
SELECT r.*, b.name AS building_name
FROM rooms r
JOIN buildings b ON b.id = r.building_id
WHERE b.user_id = auth.uid()
  AND r.status = 'AVAILABLE'
  AND r.deleted_at IS NULL
  AND b.deleted_at IS NULL
ORDER BY b.name, r.floor, r.name;
```

**Hoặc giường trống (cho KTX/Sleepbox):**
```sql
SELECT bd.*, r.name AS room_name, b.name AS building_name
FROM beds bd
JOIN rooms r ON r.id = bd.room_id
JOIN buildings b ON b.id = r.building_id
WHERE b.user_id = auth.uid()
  AND bd.status = 'AVAILABLE'
  AND bd.deleted_at IS NULL
ORDER BY b.name, r.name, bd.name;
```

#### Bước 3: Kiểm Tra Tiền Cọc Đã Có

**Lấy danh sách deposits của khách:**
```sql
SELECT d.*
FROM deposits d
WHERE d.user_id = auth.uid()
  AND d.tenant_id = :tenant_id
  AND d.status = 'CONFIRMED'
  AND (d.room_id = :room_id OR d.bed_id = :bed_id)
ORDER BY d.deposit_date DESC;
```

**Tính tổng cọc:**
```sql
SELECT COALESCE(SUM(amount), 0) AS total_deposit_paid
FROM deposits
WHERE tenant_id = :tenant_id
  AND status = 'CONFIRMED'
  AND (room_id = :room_id OR bed_id = :bed_id);
```

#### Bước 4: Chọn Dịch Vụ

**Danh sách dịch vụ:**
```sql
SELECT * FROM services
WHERE user_id = auth.uid()
  AND deleted_at IS NULL
ORDER BY
  CASE
    WHEN is_mandatory THEN 0
    WHEN is_default THEN 1
    ELSE 2
  END,
  name;
```

**4 Loại Dịch Vụ:**

1. **FIXED** - Cố định (VD: Wifi 100k/tháng)
2. **PER_PERSON** - Theo người (VD: Vệ sinh 50k/người)
3. **PER_ROOM** - Theo phòng (VD: Wifi 100k/phòng)
4. **METER_READING** - Theo công tơ (VD: Điện, nước)

#### Bước 5: Tạo Hợp Đồng

```sql
INSERT INTO contracts (
  user_id,
  tenant_id,
  room_id,              -- Nếu thuê phòng
  bed_id,               -- Nếu thuê giường (1 trong 2)
  contract_number,      -- Auto-generated by trigger
  status,
  signed_date,
  start_date,
  end_date,
  rent_price,
  payment_cycle,
  total_deposit,
  deposit_paid,         -- Auto-calculated by trigger
  initial_electricity_reading,
  initial_water_reading,
  notes
) VALUES (
  auth.uid(),
  :tenant_id,
  :room_id,
  NULL,
  NULL,                 -- Trigger will generate
  'ACTIVE',
  '2025-11-19',
  '2025-11-20',
  '2026-11-20',         -- 12 months
  3000000,
  'MONTHLY',
  3000000,
  0,                    -- Will be auto-calculated
  100,
  50,
  'Hợp đồng 12 tháng'
);
```

#### Bước 6: Thêm Dịch Vụ Vào Hợp Đồng

```sql
-- Điện (METER_READING)
INSERT INTO contract_services (contract_id, service_id, unit_price, initial_reading)
VALUES (:contract_id, :electricity_service_id, 3500, 100);

-- Nước (METER_READING)
INSERT INTO contract_services (contract_id, service_id, unit_price, initial_reading)
VALUES (:contract_id, :water_service_id, 25000, 50);

-- Wifi (FIXED)
INSERT INTO contract_services (contract_id, service_id, unit_price)
VALUES (:contract_id, :wifi_service_id, 100000);

-- Vệ sinh (PER_PERSON)
INSERT INTO contract_services (contract_id, service_id, unit_price)
VALUES (:contract_id, :cleaning_service_id, 50000);
```

### Tự Động Hóa (Triggers)

Khi tạo hợp đồng, hệ thống **tự động**:

1. ✅ **Tính deposit_paid** từ bảng deposits (Migration 012)
2. ✅ **Đánh dấu deposits** → `CONVERTED`
3. ✅ **Cập nhật room/bed status** → `OCCUPIED`
4. ✅ **Cập nhật tenant status** → `ACTIVE`
5. ✅ **Generate contract_number** (nếu có trigger)

## 3. GIA HẠN HỢP ĐỒNG

Hệ thống hỗ trợ **2 cách gia hạn**:

### Cách 1: Gia Hạn Đơn Giản (UPDATE_EXISTING)

**Khuyến nghị:** Dùng cho hầu hết trường hợp

**Quy trình:**

1. Staff gọi function:
```sql
SELECT create_simple_extension(
  p_contract_id := :contract_id,
  p_extension_months := 12,
  p_new_rent_price := 3200000,  -- Hoặc NULL nếu giữ nguyên
  p_notes := 'Gia hạn 12 tháng, tăng giá 200k'
);
-- Returns: extension_id
```

2. Review thông tin extension (status = DRAFT)

3. Approve extension:
```sql
UPDATE contract_extensions
SET status = 'APPROVED'
WHERE id = :extension_id;
```

4. Trigger tự động:
   - Cập nhật `contracts.end_date`
   - Cập nhật `contracts.rent_price` (nếu có)
   - Cập nhật `contracts.status` → `EXTENDED`

### Cách 2: Tạo Hợp Đồng Mới (CREATE_NEW)

**Khuyến nghị:** Dùng khi cần audit trail đầy đủ

**Quy trình:**

```sql
SELECT create_new_contract_extension(
  p_contract_id := :contract_id,
  p_extension_months := 12,
  p_new_rent_price := 3200000,  -- Hoặc NULL
  p_new_deposit := NULL,         -- NULL = giữ nguyên
  p_notes := 'Gia hạn 12 tháng'
);
-- Returns: new_contract_id
```

**Hệ thống tự động:**
- Tạo contract mới với `parent_contract_id` = old contract
- Copy services từ HĐ cũ sang HĐ mới
- Đánh dấu HĐ cũ: `status` = `EXTENDED`
- HĐ mới: `status` = `ACTIVE`

### So Sánh 2 Cách

| Tiêu chí | UPDATE_EXISTING | CREATE_NEW |
|----------|-----------------|------------|
| **Đơn giản** | ✅ Rất đơn giản | ⚠️ Phức tạp hơn |
| **Database size** | ✅ Nhẹ | ❌ Tăng records |
| **Audit trail** | ⚠️ Chỉ có extension_history | ✅ Đầy đủ nhất |
| **Invoice tracking** | ✅ Liên tục | ⚠️ Phải link qua parent |
| **Khuyến nghị** | **Dùng mặc định** | Dùng khi bắt buộc audit |

## 4. CHUYỂN PHÒNG / NHƯỢNG HỢP ĐỒNG

### Loại Transfer

1. **TENANT_CHANGE** - Nhượng hợp đồng (khách cũ → khách mới, cùng phòng)
2. **ROOM_CHANGE** - Chuyển phòng (cùng khách, khác phòng/giường)
3. **BOTH_CHANGE** - Cả 2 (khách mới + phòng mới)

### A. Nhượng Hợp Đồng (TENANT_CHANGE)

**Quy trình:**

```sql
-- Step 1: Tạo transfer record
SELECT create_tenant_transfer(
  p_contract_id := :contract_id,
  p_new_tenant_id := :new_tenant_id,
  p_transfer_date := CURRENT_DATE,
  p_transfer_fee := 500000,  -- Phí nhượng HĐ
  p_reason := 'Khách cũ chuyển công tác'
);
-- Returns: transfer_id
```

**Hệ thống tự động tính:**
- `old_tenant_outstanding`: Công nợ của khách cũ từ invoices chưa trả

**Step 2: Review và approve:**

```sql
UPDATE contract_transfers
SET status = 'APPROVED'
WHERE id = :transfer_id;
```

**Trigger tự động:**
- `contracts.tenant_id` → new tenant
- Old tenant status → `INACTIVE` (nếu không còn HĐ nào)
- New tenant status → `ACTIVE`
- `contracts.status` → `TRANSFERRED`

### B. Chuyển Phòng (ROOM_CHANGE)

```sql
SELECT create_room_transfer(
  p_contract_id := :contract_id,
  p_new_room_id := :new_room_id,     -- Hoặc p_new_bed_id
  p_new_bed_id := NULL,
  p_new_rent_price := 3500000,       -- NULL = giữ nguyên
  p_move_date := '2025-12-01',
  p_reason := 'Nâng cấp lên phòng lớn hơn'
);
```

**Trigger tự động:**
- Old room/bed → `AVAILABLE`
- New room/bed → `OCCUPIED`
- `contracts.room_id` hoặc `contracts.bed_id` → new room/bed
- Update `contracts.rent_price` (nếu có)

### C. Xử Lý Deposit Khi Transfer

**3 tùy chọn:**

1. **KEEP_EXISTING** - Khách cũ giữ cọc, khách mới đóng cọc mới
2. **TRANSFER_TO_NEW** - Chuyển cọc từ khách cũ sang khách mới
3. **REFUND_OLD** - Hoàn cọc khách cũ, khách mới đóng mới

```sql
UPDATE contract_transfers
SET
  deposit_transfer_type = 'REFUND_OLD',
  old_tenant_deposit_refund = 3000000,
  new_tenant_deposit_paid = 3000000
WHERE id = :transfer_id;
```

## 5. THANH LÝ HỢP ĐỒNG (CHECK-OUT)

### Quy Trình Thanh Lý

#### Step 1: Tạo Termination Record

```sql
INSERT INTO contract_terminations (
  user_id,
  contract_id,
  termination_type,
  termination_date,
  actual_move_out_date,
  status
) VALUES (
  auth.uid(),
  :contract_id,
  'NORMAL',              -- Hoặc EARLY_TENANT, EARLY_OWNER, BREACH, FORFEIT
  CURRENT_DATE,
  '2025-12-15',          -- Ngày khách chuyển đi
  'DRAFT'
);
```

**Trigger tự động tính:**
- ✅ `outstanding_debt`: Tổng công nợ từ invoices chưa trả
- ✅ `prorated_rent`: Tiền phòng ngày lẻ (tính theo ngày thực tế)
- ✅ `prorated_services`: Dịch vụ tính theo ngày
- ✅ `total_deposit`: Lấy từ contract

#### Step 2: Nhập Phí Phạt/Hư Hỏng (Manual)

```sql
UPDATE contract_terminations
SET
  -- Phí phạt
  early_termination_fee = 1000000,      -- Phạt chấm dứt sớm
  notice_violation_fee = 500000,        -- Phạt không báo trước đủ ngày

  -- Hư hỏng
  damage_fee = 300000,
  damage_description = 'Vỡ kính cửa sổ, hư bóng đèn',
  damage_images = '["/uploads/damage1.jpg", "/uploads/damage2.jpg"]'::jsonb,

  -- Khác
  cleaning_fee = 200000,
  other_fees = 100000,
  other_fees_description = 'Mất chìa khóa'

WHERE id = :termination_id;
```

#### Step 3: Xem Tính Toán Tự Động

```sql
SELECT
  outstanding_debt,
  prorated_rent,
  prorated_services,
  total_deductions,      -- GENERATED column
  refund_amount          -- GENERATED column (deposit - deductions)
FROM contract_terminations
WHERE id = :termination_id;
```

**Ví dụ:**
```
Total Deposit:         3,000,000 VND
------------------------------------
Outstanding Debt:        500,000 VND
Prorated Rent:           300,000 VND
Prorated Services:        50,000 VND
Early Termination Fee: 1,000,000 VND
Damage Fee:              300,000 VND
Cleaning Fee:            200,000 VND
------------------------------------
Total Deductions:      2,350,000 VND
====================================
REFUND TO TENANT:        650,000 VND
```

**Nếu âm (tenant nợ):**
```
Total Deposit:         3,000,000 VND
Total Deductions:      3,500,000 VND
====================================
TENANT OWES:            -500,000 VND  ❌ Phải thu thêm!
```

#### Step 4: Approve Termination

```sql
UPDATE contract_terminations
SET status = 'APPROVED'
WHERE id = :termination_id;
```

**Trigger tự động:**
- `contracts.status` → `TERMINATED`
- `contracts.actual_end_date` → termination date
- Room/bed → `AVAILABLE` (via contract trigger)
- Tenant → `INACTIVE` (nếu không còn HĐ nào)

#### Step 5: Hoàn Trả Cọc (Nếu > 0)

```sql
UPDATE contract_terminations
SET
  refund_method = 'BANK_TRANSFER',
  refund_date = CURRENT_DATE,
  refund_receipt_url = '/uploads/receipt_123.pdf',
  status = 'COMPLETED'
WHERE id = :termination_id;
```

## 6. QUY TẮC NGHIỆP VỤ

### 6.1 Ràng Buộc Dữ Liệu

#### Contracts Table

```sql
-- Phải chọn room HOẶC bed (không được cả 2)
CONSTRAINT contracts_must_have_room_or_bed CHECK (
  (room_id IS NOT NULL AND bed_id IS NULL) OR
  (room_id IS NULL AND bed_id IS NOT NULL)
)

-- Ngày bắt đầu <= Ngày kết thúc
CONSTRAINT contracts_dates_valid CHECK (start_date <= end_date)

-- Giá thuê >= 0
CONSTRAINT contracts_rent_price_non_negative CHECK (rent_price >= 0)

-- Deposit remaining = total - paid (GENERATED column)
deposit_remaining GENERATED ALWAYS AS (total_deposit - deposit_paid) STORED
```

#### Contract Terminations

```sql
-- Phải có refund_method nếu refund_amount > 0
CONSTRAINT terminations_refund_method_required_if_refund CHECK (
  (refund_amount <= 0) OR (refund_method IS NOT NULL)
)

-- Move out date phải sau start date
CONSTRAINT terminations_move_out_after_start CHECK (
  actual_move_out_date >= (SELECT start_date FROM contracts WHERE id = contract_id)
)
```

### 6.2 Status Workflow

#### Room/Bed Status Flow

```
AVAILABLE → RESERVED (deposit) → OCCUPIED (active contract) → AVAILABLE (terminated)
     ↓                                    ↓
MAINTENANCE ←---------------------------→ UNAVAILABLE
```

#### Tenant Status Flow

```
PROSPECT → DEPOSITED → ACTIVE → INACTIVE
                          ↓
                      BLACKLIST (nếu vi phạm nghiêm trọng)
```

#### Contract Status Flow

```
DRAFT → ACTIVE → EXTENDED → TERMINATED
           ↓         ↓           ↓
           └────→ TRANSFERRED    └──→ EXPIRED
```

### 6.3 Tính Toán Tự Động

#### Deposit Paid (Auto-calculated)

**Khi tạo contract:**
```sql
-- Trigger tự động tính deposit_paid từ bảng deposits
deposit_paid = SUM(deposits.amount)
WHERE deposits.tenant_id = contract.tenant_id
  AND deposits.status = 'CONFIRMED'
  AND (deposits.room_id = contract.room_id OR deposits.bed_id = contract.bed_id)
```

#### Prorated Rent (Tiền Phòng Ngày Lẻ)

**Công thức:**
```
Số ngày trong tháng = 30 (hoặc 31, tùy tháng)
Đơn giá ngày = Rent Price / Số ngày trong tháng
Tiền phòng ngày lẻ = Đơn giá ngày × Số ngày đã ở
```

**Ví dụ:**
```
Rent: 3,000,000 VND/tháng
Move out: 15/12/2025 (tháng 12 có 31 ngày)
Daily rate: 3,000,000 / 31 = 96,774 VND/ngày
Prorated rent: 96,774 × 15 = 1,451,610 VND
```

#### Invoice Remaining Amount (Auto-calculated)

```sql
remaining_amount GENERATED ALWAYS AS (total_amount - paid_amount) STORED
```

### 6.4 Xử Lý Đặc Biệt

#### Multiple Active Contracts

**Hệ thống CHO PHÉP:**
- 1 tenant có nhiều contracts ACTIVE (thuê nhiều phòng)
- 1 room/bed CHỈ có 1 contract ACTIVE tại 1 thời điểm

**Validate:**
```sql
-- Không cho phép tạo contract mới nếu room đã OCCUPIED
SELECT COUNT(*) FROM contracts
WHERE room_id = :room_id
  AND status = 'ACTIVE'
  AND deleted_at IS NULL;
-- Must return 0
```

#### Discount Handling

**Format (JSONB array):**
```json
[
  {
    "month": 1,
    "amount": 500000,
    "reason": "Khuyến mãi tháng đầu"
  },
  {
    "month": 12,
    "amount": 300000,
    "reason": "Giảm giá cuối năm"
  }
]
```

**Apply discount trong Invoice:**
```sql
-- Xác định tháng thứ mấy của contract
month_number = EXTRACT(MONTH FROM AGE(invoice.billing_period_start, contract.start_date)) + 1

-- Lấy discount cho tháng đó
discount = (contract.discounts::jsonb @> '[{"month": month_number}]')
```

#### Payment Cycle

**Chu kỳ thanh toán:**
- `MONTHLY`: Hóa đơn hàng tháng
- `QUARTERLY`: Hóa đơn 3 tháng/lần
- `SEMI_ANNUAL`: Hóa đơn 6 tháng/lần
- `ANNUAL`: Hóa đơn 1 năm/lần

**Generate invoices:**
```sql
-- Monthly
INSERT INTO invoices (billing_period_start, billing_period_end)
VALUES (
  '2025-11-20',  -- Contract start
  '2025-12-19'   -- +1 month -1 day
);

-- Quarterly
INSERT INTO invoices (billing_period_start, billing_period_end)
VALUES (
  '2025-11-20',
  '2026-02-19'   -- +3 months -1 day
);
```
