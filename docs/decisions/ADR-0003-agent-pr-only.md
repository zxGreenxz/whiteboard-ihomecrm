# ADR-0003 — quy trình phát hành

Quyết định hiện hành nằm trong [Project Contract](../engineering/PROJECT_CONTRACT.md) §3–5.
Giữ đường dẫn này để các liên kết cũ còn dùng được.

Repo dùng trunk-based với bước promote app riêng sau khi CI đúng SHA đạt.
Quy tắc draft PR, review và ghi schema tra Contract; trạng thái kiểm soát ngoài repo phải đo lại.
Bản ADR cũ chứa điều kiện token và số liệu CI đã hết hiệu lực; lịch sử đầy đủ nằm trong Git.
