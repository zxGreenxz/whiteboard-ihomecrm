## 📝 NOTES & ASSUMPTIONS

### Areas (Khu vực)
- **Optional relationship**: `buildings.area_id` is nullable
- **Cascade delete**: When area deleted, buildings.area_id set to NULL (not cascade delete)
- **Use case**: For organizations managing properties across multiple districts/zones
- **Alternative names**: Could be "Zones", "Regions", "Districts" depending on business context

### Signature Templates
- **Storage**: Signature images stored in Supabase Storage bucket `signatures/`
- **Path format**: `{user_id}/{timestamp}-{filename}`
- **DRAW type**: Canvas data stored as JSONB for potential re-editing
- **TEXT type**: Font rendering happens client-side before upload
- **Security**: RLS ensures users only see their own signatures

### Building Map
- **Separate page**: Not a widget/component, full dedicated route
- **Performance**: Group/chunk operations done in useMemo for large buildings
- **Configurable**: ROOMS_PER_ROW can be adjusted per building
- **Real-time**: Should subscribe to room status changes via Supabase Realtime
- **Mobile**: Grid should be responsive (scroll horizontally on small screens)
