# Zalo — tạm ngưng

Phát triển, tối ưu và kiểm chuyên biệt Zalo đang tạm ngưng theo yêu cầu.
Chỉ đọc [hồ sơ Zalo/Copilot](../deferred/zalo-copilot.md) khi người dùng mở lại phạm vi này.

Hồ sơ lưu mốc Git để khôi phục runbook cũ. Các phép kiểm chưa chạy vẫn là chưa kiểm;
trang này không xác nhận trạng thái worker hoặc tính năng đang chạy.
