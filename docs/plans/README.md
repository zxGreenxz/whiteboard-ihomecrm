# Plan và spec — đọc theo nhiệm vụ

Thư mục này chứa hồ sơ cũ và một số plan mới đã được giao; không còn coi là thư mục đóng băng hoặc danh sách đầy đủ có số đếm cố định.
Plan mới khi cần lưu đặt tại `docs/superpowers/plans/YYYY-MM-DD-<slug>.md`; spec thiết kế ở `docs/superpowers/specs/`. Không tạo plan chỉ vì mẫu skill yêu cầu khi task đã rõ.

Chỉ mở đúng plan user giao hoặc được source/task dẫn tới. Đối chiếu trạng thái bằng code và evidence hiện tại; tên/ngày file và checkbox chưa đánh dấu không tự tạo việc cần làm.

- Các plan `ra-soat-2026-09-15/` là đầu vào của đợt rà riêng; không chạy lại toàn bộ cho thay đổi mới.
- Bản [tách dữ liệu V1](PLAN-TACH-DU-LIEU-DA-CONG-TY.md) đã được thay bởi V2; bản V1 cất kho.
- [Báo cáo V5 collection](EXEC-REPORT-V5-COLLECTION-20260722.md) là evidence lịch sử đã cất kho.
- Các file còn lại được giữ tại chỗ để tránh phá tham chiếu; muốn triển khai tiếp phải chốt phạm vi hiện tại.

Luật đang áp dụng ở [Project Contract](../engineering/PROJECT_CONTRACT.md), nghiệp vụ ở [domain tương ứng](../he-thong/README.md). Không dùng plan thay hai nguồn này.
