# Hướng dẫn khởi tạo dữ liệu trên máy tính dành cho người mới bắt đầu

Để khởi tạo dữ liệu hệ thống nhà thuê lên phần mềm, bạn vui lòng đăng ký và đăng nhập tài khoản trên phần mềm quản lý Bất động sản Resident. Cách đăng ký và đăng nhập tài khoản, bạn truy cập link: [Hướng dẫn đăng ký và đăng nhập phần mềm Resident trên máy tính](https://resident.vn/huong-dan-dang-ky-va-dang-nhap-phan-mem-resident) để tìm hiểu chi tiết nhé.

Sau khi đăng nhập tài khoản thành công, phần mềm sẽ hiển thị giao diện như sau:

### 1.4 Mẹo tạo dữ liệu Tòa nhà/Phòng/Giường nhanh từ file dữ liệu mẫu

Đối với các đơn vị có quy mô Căn hộ/Phòng/Giường lớn thì việc tạo thông tin hàng loạt là tính năng cần thiết. Để hỗ trợ người dùng tạo dữ liệu nhanh hơn, trên thiết bị máy tính Resident đã thiết kế tính năng tạo dữ liệu nhanh từ file excel mẫu. Cụ thể:

**Bước 1**: Tại màn hình chính ấn chọn mục **Danh mục dữ liệu** ⇒ **Tòa nhà**

**Bước 2**: Ấn nút **Nhập dữ liệu** hình mũi tên đi lên

<figure><img src="https://2587001524-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FEuMZM1RGkR50RkNDbUkL%2Fuploads%2FmVep5Qv1EzkHlit03guF%2Fimage.png?alt=media&#x26;token=ecf1dca3-1754-4b47-8c9b-a2fbe2a6c01c" alt=""><figcaption></figcaption></figure>

**Bước 3**: Tại đây hệ thống sẽ hiển thị chi tiết màn Nhập dữ liệu, bạn hãy ấn vào "**Tải file mẫu tại đây**" để tải file mẫu xuống.

<figure><img src="https://2587001524-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FEuMZM1RGkR50RkNDbUkL%2Fuploads%2FgdEq8Y6o2OiKy33jE2Ci%2Fimage.png?alt=media&#x26;token=8454ca55-54f4-4595-8cb1-1ce1fa419dc5" alt=""><figcaption></figcaption></figure>

**Bước 4**: Mở file mẫu và điền dữ liệu căn hộ theo các trường thông tin hệ thống yêu cầu nhập.&#x20;

_Lưu ý:_

* _Những mục đánh dấu **(\*)** là những mục bắt buộc phải điền thông tin._
* _Hãy xem **ví dụ mẫu** trước khi nhập dữ liệu để đảm bảo tính chính xác._
* _Trước khi nhập dữ liệu, bôi đen toàn bộ bảng và chuyển về dạng Text._

<figure><img src="https://2587001524-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FEuMZM1RGkR50RkNDbUkL%2Fuploads%2F7WX7BWnLIS2nNeKkGthp%2FScreen%20Shot%202022-11-15%20at%2017.51.35.png?alt=media&#x26;token=8f336d39-2eb3-4fc3-84fa-f45ef3a9e1d2" alt=""><figcaption></figcaption></figure>

**Bước 5**: Đẩy file dữ liệu chứa thông tin Tòa nhà, Phòng, Giường cần tạo lên hệ thống bằng cách ấn nút "**Chọn file**" hoặc "**Kéo thả file**" vào màn Chi tiết nhập dữ liệu. Sau đó ấn nút **Nhập dữ liệu**

<figure><img src="https://2587001524-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FEuMZM1RGkR50RkNDbUkL%2Fuploads%2FDn6NVZbiq8UYsRbQb02D%2Fimage.png?alt=media&#x26;token=0591fba0-78ce-4bcb-baa5-bf4628bbda6f" alt=""><figcaption></figcaption></figure>

Nếu bạn nhập dữ liệu thành công, hệ thống sẽ bắn thông báo "Dữ liệu đã được TẠO thành công" và hiển thị thông tin chi tiết tại các màn **Danh sách Tòa nhà, Danh sách phòng** và **Danh sách giường.** Trên đây là hướng dẫn cách tạo Tòa nhà, Phòng, Giường trên phần mềm quản lý Bất động sản Resident từ thiết bị máy tính.
